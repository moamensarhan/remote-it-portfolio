What is Active Directory?

To understand Active Directory, one must first learn what a directory service is. A directory service is a system that keeps track of users, computers and groups, and unique characteristics concerning those objects such as the permissions they enjoy. This allows centralized management over a domain and its contents. Active Directory is Microsoft's proprietary directory service. 

How do you create a user in Active Directory?

First, a location for a directory to create users must be designated, preferably within a domain that includes both users and computers for simplicity's sake. After establishing such a directory, it will do to right click either the empty tab on the right, or the users directory itself, then "New", then fill out the user's information according to policy. Many organizations prefer a standardized format, such as the person's first name initial + their last name (i.e. msarhan). The "User logon name" is what users will use to log into the domain. Initials can be left blank unless required by organization's policy.
